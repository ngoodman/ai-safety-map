# AI safety map

An interactive map of how AI risks arise and escalate, from four sources to six outcomes, made for the AI safety lecture in Minds and Machines at Stanford (Fall 2026).

Live: https://ngoodman.github.io/ai-safety-map/

Click any box to trace what feeds it and what it leads to, or pick one of the lecture paths. Link straight to a path with `#catastrophe`, `#control`, `#disempowerment`, `#upheaval`, `#upside` or `#incident`, or to a box by its id (for example `#B6`, epistemic decay).

The whole map is one self-contained file, `index.html`.
